# 🌐 avrism.xyz

the source code to my personal website (so far) ✨

## 🧭 Explore the site

- 🏠 The homepage brings together an introduction, social links, and recent blog posts.
- 📰 Blog templates live in `src/Views/blogs/`.
- 📬 The contact form lives in `src/Views/core/contact.twig`.
- 🎨 Shared page layouts live in `src/Views/layouts/`.

## 🛠️ Project pieces

- 🐘 PHP powers the application.
- 🧩 Twig renders the page templates.
- 🛣️ Bramus Router handles routes.
- 📦 `composer.json` lists dependencies and autoload configuration.
- ⚙️ `.env.example` documents configuration variables.
- 🗃️ `schema.sql` contains the database schema.
- 🚪 `public/index.php` is the web entry point.
